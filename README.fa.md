# پنل SSH VPN

این پنل برای مدیریت حساب‌های تونل SSH و SOCKS روی Ubuntu 24.04 است. کاربران VPN از همان پورت SSH سرور برای تونل استفاده می‌کنند، ولی امکان شِل، اجرای دستور و SFTP ندارند. وب پنل با Django، PostgreSQL، Gunicorn و Nginx اجرا می‌شود. مخزن خصوصی است و هر سرور برای دریافت آن باید دسترسی خواندن گیت‌هاب داشته باشد.

## بکاپ و جابه‌جایی سرور

از مسیر **Settings → Backup and restore** یک عبارت عبور حداقل ۱۶ کاراکتری وارد کنید، بکاپ بسازید و فایل `.svpb` را دانلود کنید. فایل با AES-256-GCM رمزگذاری می‌شود؛ عبارت عبور را جدا از فایل نگه دارید.

بکاپ شامل **تمام رکوردهای PostgreSQL**، حساب‌ها و هش رمز مدیران، رمزهای VPN رمزگذاری‌شده و کلید لازم برای بازیابی آن‌ها، مشخصات کامل حساب‌های لینوکسی VPN و هش رمز آن‌ها، سیاست‌های انقضا و سقف اتصال، گزارش عملیات، آمار مصرف ذخیره‌شده و نسخه‌ای از تنظیمات پنل، Nginx و SSH است. هیچ حساب یا رکورد دیتابیس از بکاپ حذف یا فیلتر نمی‌شود. UID کاربران لینوکسی در سرور مقصد با توجه به حساب‌های موجود آن سرور تعیین می‌شود. اتصال‌های فعال و IP لحظه‌ای آن‌ها وضعیت موقت سرور هستند و پس از جابه‌جایی باید دوباره متصل شوند.

برای ریستور، **همین نسخه** را ابتدا روی سرور Ubuntu 24.04 جدید نصب کنید. فایل را در صفحهٔ بکاپ بارگذاری، عبارت عبور را وارد و جایگزینی اطلاعات پنل مقصد را تأیید کنید. پیش از تغییر داده‌های اصلی، فایل و دیتابیس آن بررسی و یک نسخهٔ بازیابی روی سرور مقصد ذخیره می‌شود. دیتابیس و مدیران پنل مقصد با داده‌های بکاپ جایگزین می‌شوند. IP یا دامنهٔ وب، SSL، مشخصات اتصال دیتابیس و پورت SSH خود سرور مقصد حفظ می‌شود؛ پس از راه‌اندازی مجدد پنل، با حساب مدیر موجود در بکاپ وارد شوید. اگر مقصد کاربر VPN اضافه‌ای داشته باشد که در فایل نیست، ریستور متوقف می‌شود تا اطلاعات آن کاربر از دست نرود. سقف بارگذاری فایل ۱ گیگابایت است.

اگر پنل هنوز HTTP است، عبارت عبور و فایل هنگام انتقال در مرورگر محافظت شبکه‌ای ندارند. برای استفاده از بخش بکاپ روی شبکهٔ غیرقابل اعتماد، ابتدا SSL را فعال کنید یا با تونل SSH مدیریتی وارد پنل شوید.

## نصب و به‌روزرسانی

نصب تازه روی سرور ابتدا با HTTP بالا می‌آید و نام کاربری و رمز مدیر در آغاز نصب پرسیده می‌شود:

```bash
git clone git@github.com:EmadNajafi/sshpanel.git
cd sshpanel
sudo bash deploy/install.sh SERVER_PUBLIC_IP
```

برای نصب موجود، دوباره نصب نکنید. در همان مخزن روی سرور اجرا کنید:

```bash
cd /root/sshpanel
GIT_SSH_COMMAND='ssh -i /root/.ssh/sshpanel_deploy -o IdentitiesOnly=yes' git pull --ff-only
sudo bash deploy/upgrade.sh
```

وب پنل روی پورت ۸۰ و آدرس IP یا دامنهٔ واردشده باز می‌شود. VPN از پورت فعلی SSH سرور استفاده می‌کند؛ این پورت از داخل تنظیمات پنل نیز قابل تغییر است. برای SSL اختیاری، دامنه را به سرور وصل کنید و دستور `sudo menu ssl panel.example.com admin@example.com` را اجرا کنید.

نصب آزمایشی `sudo bash deploy/install.sh --local-test` پنل را فقط روی `127.0.0.1:8080` باز می‌کند. برای دسترسی، از رایانهٔ خودتان تونل مدیریتی `ssh -N -L 127.0.0.1:8080:127.0.0.1:8080 root@SERVER_IP` بسازید و `http://localhost:8080/login/` را باز کنید.
