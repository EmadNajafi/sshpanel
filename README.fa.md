# پنل SSH VPN

این پروژه برای ساخت و مدیریت حساب‌های **تونل SSH/SOCKS** روی Ubuntu 24.04 است. مدیریت کاربران از طریق وب انجام می‌شود. فرمان `menu` روی خود سرور برای گرفتن SSL، تمدید گواهی، بررسی سرویس‌ها، دیدن لاگ و پشتیبان‌گیری پایگاه‌داده است.

## اجزای پروژه

- **Django:** ورود مدیر و صفحهٔ ساخت، غیرفعال‌سازی، فعال‌سازی، تغییر رمز و حذف حساب.
- **PostgreSQL:** نگهداری نام حساب‌ها، وضعیت و سابقهٔ عملیات. رمز کاربران VPN در پایگاه‌داده ذخیره نمی‌شود.
- **ابزار `sshvpnctl`:** فقط چند عمل مشخص روی حساب‌های گروه `sshvpn` را با دسترسی ریشه انجام می‌دهد. برنامهٔ وب به دستورهای آزاد سیستم دسترسی ندارد.
- **OpenSSH جداگانه:** روی پورت ۲۲۲۲ برای تونل. سرویس SSH مدیریتی سرور از این سرویس جدا است.
- **Nginx + Gunicorn:** ارائهٔ پنل وب؛ Certbot برای HTTPS.

## محدودیت مهم پیش از استفادهٔ واقعی

برای کاربران VPN، شِل، اجرای دستور و SFTP با `MaxSessions 0` بسته می‌شود و گروه آن‌ها در SSH مدیریتی سرور رد می‌شود. با این حال، **تونل SSH به‌تنهایی می‌تواند به سرویس‌های داخلی قابل‌دسترسی از سرور وصل شود.** به همین دلیل سرویس VPN در نصب اولیه فقط روی `127.0.0.1` گوش می‌دهد. پیش از بازکردن عمومی پورت ۲۲۲۲ باید سیاست خروجی شبکه روی VPS آزمایشی پیاده و با اتصال واقعی آزمایش شود.

این نسخه هنوز آزمون نصب کامل روی Ubuntu 24.04 و آزمون جداسازی شبکه را نگذرانده است؛ آن را روی سرور اصلی یا برای کاربران واقعی فعال نکنید.

## نصب آزمایشی پس از تأیید امنیت شبکه

۱. دامنه را به IP سرور وصل کنید و از VPS یک snapshot بگیرید. اتصال SSH مدیریتی خود را باز نگه دارید.

۲. مخزن را روی Ubuntu 24.04 دریافت کنید و از ریشهٔ آن اجرا کنید:

```bash
sudo bash deploy/install.sh panel.example.com admin@example.com
```

۳. در پایان نصب، حساب مدیر وب را بسازید. سپس روی سرور اجرا کنید:

```bash
sudo menu ssl
sudo menu status
```

با `sudo menu` گزینه‌های تعاملی نمایش داده می‌شوند. نصب‌کننده دیوار آتش سرور و پورت SSH مدیریتی را تغییر نمی‌دهد. جزئیات فنی و آزمون‌های محلی در [README.md](README.md) آمده است.
